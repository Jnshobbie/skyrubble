# Skyrubble
Dev: `npm install && npm run dev` · Build: `npm run build` · Level 2 test (dragons + orcs): `/?level=2` · 3D is the default; sprite fallback: `/?hero=2d&enemy=2d`
PC: A/D or arrows, Space/W jump, J/K/click shoot, R restart. Mobile: on-screen buttons (src/input.ts).
Look: src/grade.ts (grading) and PAL in src/level.ts (colors). Boss: Boss class in src/foes.ts (FSM, hook clips in enter()).
